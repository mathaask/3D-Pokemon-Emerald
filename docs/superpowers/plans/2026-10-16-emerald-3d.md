# Emerald 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the user's Pokémon Emerald ROM in a purpose-built GBA core and present it through a new Three.js 3D renderer (overworld + battles), keeping every original mechanic and story event.

**Architecture:** `src/gba` is a DOM-free GBA emulator (CPU/bus/PPU/APU/DMA/timers/flash/RTC, HLE BIOS). `src/game` reads Emerald's live structs from emulated RAM via pokeemerald symbol addresses. `src/render` builds 3D scenes from that state and from live VRAM/palette data decoded in shaders.

**Tech Stack:** TypeScript 5, Vite, Three.js (WebGL2), vitest, tsx (Node tools), puppeteer-core + system Chrome for headless screenshots.

**Spec:** `docs/superpowers/specs/2026-10-16-emerald-3d-design.md`

## Global Constraints

- No Nintendo assets in the repo; ROM is read at runtime (`/Pokemon_Emerald-.gba` served by Vite, or drag-and-drop).
- ROM must be BPEE rev 0 (SHA-1 `f3ae088181bf583e55daf962a92bb46f4f1d07b7`); other ROMs show a warning but still try to run.
- `src/gba/**` must not import DOM or Three.js (runs under Node for tests/tools).
- Framebuffer pixel format everywhere: `Uint32Array` of 0xAABBGGRR (little-endian RGBA bytes, ready for `ImageData`).
- GBA timing constants: 1232 cycles/scanline, 228 scanlines/frame, 280 896 cycles/frame, 16 777 216 Hz.
- Symbols come only from `src/game/symbols.ts` (generated); never hard-code addresses elsewhere.

## Review Focus

1. Unaligned 32-bit loads (`LDR` rotates) and 16-bit loads (`LDRH` rotates, `LDRSH` sign quirk) — game code relies on them; CPU tests must cover them.
2. IRQ arriving while the CPU is inside an HLE `IntrWait` — must not lose the VBlank flag (test in bios tests).
3. Flash save written mid-game then reloaded after a page refresh — sector erase/program must persist bit-exact (cart tests).
4. Map change while the 3D renderer is mid-build (warp / connection crossing) — renderer must rebuild using the new tilesets, never draw old geometry with new VRAM (overworld tests via headless screenshots).
5. Unknown scene (any `gMain.callback2` not recognised) — must fall back to 2D presentation, never a black screen (scene tests).

## Core interfaces (all tasks rely on these exact names)

```ts
// src/gba/bus.ts
export class Bus {
  bios: Uint8Array; ewram: Uint8Array; iwram: Uint8Array; io: Uint8Array /*0x400*/;
  pram: Uint8Array; vram: Uint8Array; oam: Uint8Array; rom: Uint8Array;
  io16: Uint16Array; pram16: Uint16Array; vram16: Uint16Array; oam16: Uint16Array; // views
  read8(a: number): number; read16(a: number): number; read32(a: number): number;
  write8(a: number, v: number): void; write16(a: number, v: number): void; write32(a: number, v: number): void;
}
// src/gba/ppu.ts
export class Ppu {
  constructor(bus: Bus);
  framebuffer: Uint32Array;           // 240*160 final image
  overlay: Uint32Array;               // 240*160, only layers in overlayMask, alpha 0 where empty
  overlayMask: number;                // bit0..3 = BG0..BG3, bit4 = OBJ; 0 disables overlay pass
  renderScanline(y: number): void;    // called at HBlank start of visible lines
  reset(): void;
}
// src/gba/apu.ts
export class Apu {
  constructor(sampleRate: number);
  read16(off: number): number;        // off relative to 0x04000060
  write16(off: number, v: number): void;
  fifoWrite32(channel: 0 | 1, v: number): void;
  timerOverflow(timer: number): number; // returns bitmask of FIFOs needing DMA refill (bit0=A, bit1=B)
  advance(cycles: number): void;      // generate output samples
  drain(out: Float32Array): number;   // pull interleaved stereo samples, returns frames written
}
// src/gba/gba.ts
export class Gba {
  constructor(rom: Uint8Array, opts?: { sampleRate?: number; now?: () => Date });
  bus: Bus; cpu: Cpu; ppu: Ppu; apu: Apu;
  keys: number;                        // pressed mask, bit0=A … bit9=L (1 = pressed)
  runFrame(): void;
  getSave(): Uint8Array; loadSave(d: Uint8Array): void; saveDirty: boolean;
  saveState(): Uint8Array; loadState(s: Uint8Array): void;
}
```
